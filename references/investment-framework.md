# 投资观点、市场反应与分析方法

适用于需要投资含义的产业日报/周报。目标是从新事实解释经营、预期与定价变量，再形成可修正的判断。模型按问题与证据选择方法，重大主题可多页分析，不逐条套全套模型；机构/渠道预测按research-protocol.md归属讨论，不因缺公司确认就整体取消。与[编辑规则](editorial-policy.md)配合。

## 三种输出各回答不同问题

- **产业/研究判断**：供需、成本、技术路线、合同或商业模式发生什么变化，依据到哪里。
- **股价/市场反应**：相关股票、债券或行业基准在明确窗口内如何变化，是价格观察；不能单凭同周涨跌识别该新闻的因果效应。
- **投资观点**：哪类资产或主体、什么期限，盈利/现金流、预期或估值依据怎样改变，相对倾向是什么，触发因素与推翻条件是什么。可以是产业方向、相对偏好、维持观察或暂不足以定价；数值目标价不是每篇周报的必需品。

重要且具投资关联的主线尽量回答三者，排版可合并；纯技术事件、未上市主体或无可靠价格时选择适用部分并说明缺项。不把“研究判断”全局改名为“投资观点”，也不为不重要的事件强造观点。

## 从事实走到投资含义

新信息 → 承重变量 → 收入/利润/现金流或风险溢价 → 相对既有预期的增量 → 当前价格与估值可支持的判断 → 催化与反证。只使用有证据的环节；未知不取消其他已能分析的环节。

1. 分清同比/环比增长、较公司前次指引变化和较可核市场一致预期的差异。没有带时点/口径的共识数据，就不能称“超预期”“低于买方”；可直接写较上期披露变化。
2. 辨别盈利修订、估值倍数/折现率、信用与资金约束可能各贡献什么；没有可比预期或价格数据，不能因业绩好股价跌就判“错杀”，也不能因股价涨就判“已充分定价”。“市场可能交易某变量”属于推断，要给替代解释。
3. 有完整输入时才做估值或反向估值：明确价格日期、股本/债务、预测期、会计/币种口径、可比公司和敏感参数。EPS×P/E只在同口径、同预测期、正盈利且可比的情况下用于拆解；不能用事后实际EPS解释事前预期价格。
4. 数据不足以定目标价时，给有依据的方向判断、相对研究倾向和下一验证条件；明确估值未评估。不用“仍待验证/不能等同”占据全部判断篇幅，也不虚构上涨空间、概率或安全边际。

方法选择原则与[CFA估值流程](https://www.cfainstitute.org/insights/professional-learning/refresher-readings/2026/equity-valuation-applications-and-processes)一致：适合业务、数据质量与估值目的；[经济与投资市场框架](https://www.cfainstitute.org/insights/professional-learning/refresher-readings/2026/economics-and-investment-markets)将现金流、利率与风险溢价以及预期变化连接到价格。这里应用公开摘要的概念，不声称已读取其会员完整课程。

## 由研究问题选择最小足够方法

| 当前要解释什么 | 优先考虑的分析 | 所需证据与边界 |
|---|---|---|
| 财报或指引改变了多少 | 同口径同比/环比、量价/产品组合/成本与利润桥、指引修订；再看预期差 | 不虚构分部贡献；缺共识仍可分析已披露经营变化 |
| 硬件/存储/电力的瓶颈在哪 | 供需平衡、有效产能、交期/库存/利用率、成本曲线与阶段传导 | 标称容量、采购、交付、接入和投运分开；技术迭代不自动产生等额BOM收入 |
| 算力租赁或扩产能否融资 | 项目现金流、租金/利用率/折旧/利息、期限匹配与信用利差 | 同币种可比期限与条款；收益率不直接等于信用利差，融资需求不直接等于融资恶化 |
| 模型/Agent/软件如何赚钱 | 成功任务单位经济、付费转化、队列留存、NDR、毛利与回款 | 标价不等于每成功任务成本；ARR、合同与会计收入分开，调用量不直接等于利润 |
| 收购/技术合作能否兑现 | 合同义务、阶段门槛、协同与竞争路径、必要条件和反事实 | 未交割不并表；规划协同不是已实现收益，技术自测不等于独立量产验证 |
| 当前价格是否提供机会 | 可比估值、DCF/反向DCF、情景与敏感性，选择真正必要的方法 | 输入完整才量化；可用定性情景，不设必须三情景或固定概率的配额 |

竞争格局、价值链利润分配、SCP/五力等可用于解释长期结构，只有会改变当前判断时才用。没有业务问题不单独添加“理论框架”展示页；也不把方法菜单变成每条新闻的必填表。

## 股价反应：由核心事件生成行情范围

保留原有市场数据规范；从本期重点上市公司/相关行业生成临时行情池，而非沿用固定几个指数和一家公司。公司代码、上市地、A/H/ADR、币种及基准要可比；同一公司不同市场不能无说明拼接。非上市主体可给有明确联系的行业价格背景，但标“相关市场表现”，不伪称该主体股价反应。

- 总览可用“主题／新增事实／股价反应／投资观点”，也可用主线卡片或图文；关键是将同一事件的几层信息连起来。数据未取得应写具体未取到的标的/窗口，不回填参考稿收益。
- 周表现按实际周端点；事件反应另记披露时间、盘前/盘中/盘后、首个可交易时段、观察窗和基准窗。盘后事件不能解释当日常规交易收益；回溯截止前尚无事件后交易日时，写尚无可观察反应。
- 最小价格记录：target/ticker/venue、event_id与原始披露时间、window_start/end、P0/P1及来源定位、币种/复权、价格或总回报、benchmark、return、benchmark_return、差值与局限。收盘收益与基准收益差用百分点，叫“相对基准差”，不直接叫alpha、正式异常收益或因果影响。
- 只有真的估计预期收益模型与估计窗、检查混杂事件和假设时才称正式事件研究。日常周报通常不需要为单条新闻启动回归；清楚的窗口对照加竞争解释更实用。
- 若解释市场分歧，结合已知指引/共识修订、同业表现、利率信用与同期其他消息。不能凭一条新闻和一根K线就认定跌因，也不能把所有背离推给“情绪”。

## 写进既有台账与页面

沿用theses，不另建重复的观点库。重点主线可以关联多个事件；每个事件不必各造一个观点。thesis至少明确text、对象target、期限horizon、来源claim_ids、立场stance、next_validation、invalidation，以及valuation_status（not_assessed/qualitative/modeled）；量化估值另用valuation_claim_ids链接输入、假设与计算。maintained/upgraded等跨期立场需要实际可比的上期命题；没有上期则new/pending，不倒造命中记录。

可用`takeaway_label:"投资观点",thesis_ids:["T01"]`将本页既有takeaway显示为投资观点，正文解释传导、市场证据和假设。无需投资定价判断的页保留“研究判断”或“后续观察”。台账和标签只是可检查的连接，不证明观点正确；不把改标签当成新增投资分析。

重点页验收：读者能否说出“什么改变了、为什么影响投资判断、市场表现如何、哪些定价环节未核、什么时候应改判断”。必要限制集中写清，主文优先解释可支持的结论。
